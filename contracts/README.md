# THE K.LAB · K1N0 contracts

The K1N0 collection on Ethereum: every K made in THE K.LAB can be minted once per colour combination.

## Contracts

- `src/KLab.sol`: the ERC-721 **THE K.LAB** (symbol `K1N0`). #0 is the K4NCUN0 logo, minted to the owner in the constructor; then at most 8,362 tokens, #1 to #8362, 0.0024 ETH each (owner can change). The minter picks the number (`mint(colours, title, look, id)`; `usedMap()` and `isAvailable()` let the site offer Random). A K1N0 is the clay K: the X and four head blocks always black, four colours of its own (`bytes4`: background, centre, front left, front right) from the 16-colour `PALETTE`; background never black, coloured blocks never the background. **Each combination can be minted once** (`coloursTaken`). The colours are written once at mint and never change. The holder changes only the **look** (`setLook`, gas only): an effect per colour, speed, 3D view; every look is kept with who set it and when (`looksCount`, `lookAt`), emits `MetadataUpdate` (EIP-4906) so marketplaces show it, and the story goes on with the next holder. A holder may let an app set looks for them (`setLookOperator`, looks only); transfer approvals give no look rights. The mint is closed at deploy (`setMintOpen`). Owner: price, withdraw, royalties (EIP-2981, 0 by default, max 10%), site URL, renderer (until `lockRenderer`), two-step ownership (`transferOwnership` + `acceptOwnership`).
- **Built to evolve** without touching what is minted: which looks exist is decided by the renderer (`validLook`), so a new renderer can bring new effects (it must be a contract that accepts the default look); owner-approved **extensions** (`setExtension`, public `ExtensionSet` events) can mint the remaining numbers under their own rules (`extensionMint`: allowlists, claims, other sales; same cap and unique colours) and ask marketplaces to refresh (`refreshMetadata`). `lockExtensions` stops new extensions for good (removing one stays possible). Permanent: number, colours, looks already set, 8,362 cap.
- `src/KLabRenderer2.sol` (2026-11-19): the same renderer with the words aligned (K1N0 as an open character with no owner, CC0; links to /klab). Same `KLabArt3D` and `KLabViewer`, so the art, the 3D piece and the traits are unchanged (`test/renderer2.test.cjs`). The owner deploys it and switches to it from `deploy/owner.html` (built by `npm run owner-page`); `scripts/renderer2-fork-check.cjs` rehearses it on a mainnet fork (`FORK_URL=… npx hardhat run …`).
- `src/KLabRenderer.sol`: the metadata JSON: `image` (a 3D SVG with SMIL effects, by `KLabArt3D` + `KLabArtBg` from the faces in `KLabFaces.sol`, generated by `art3d/`) and `animation_url` (the interactive 3D piece). Every effect keeps the exact palette colour of each block; effects add light and motion only.
- `src/KLabViewer.sol`: the 3D piece, a small WebGL engine (`viewer/viewer.js`, built into the contract and into `src/lib/lab/k1n0-viewer.ts` by `node viewer/build.cjs`): drag to turn, wheel or pinch to zoom, double-click for the holder's view.
- `src/KLabDeployer.sol`: deploys everything in two transactions on Ethereum mainnet.
- `v1/`: the first, retired version (paused on mainnet).

## Test

```bash
npm install
npm test                       # local suite
npx hardhat run scripts/sepolia-deploy.cjs --network sepolia  # needs KLAB_TEST_KEY (throwaway)
npx hardhat run scripts/sepolia-check.cjs --network sepolia   # needs KLAB_TEST_KEY and KLAB_ADDRESS
```

Tested on Sepolia on 2026-11-18 (one contract per transaction there: Sepolia prices code at ~1,540 gas a byte with a 16.7M gas cap per transaction, and new storage costs about four times mainnet): logo #0, mint with a random number, refusals (same colours, black background, taken number, #0), looks, history across a transfer, renderer swap, withdraw, and the site's token page. Sepolia KLab: `0xb557e1d3b21e77eaa04336335cf158813f8fadb3`; the version with extensions and look operators: `0x0e8ae80b24eb212fc9e7232f53fb726af561dfd9` (deployed before the rename to K1N0, which changed only names). Under mainnet rules a mint costs ~208k gas and a new look ~56k.

## Deploy (from your own wallet)

```bash
npm run build && npm run deploy-page
```

Serve `deploy/` on localhost (the "klab-deploy" entry of `.claude/launch.json`, or `python -m http.server 8546 --directory contracts/deploy`), open http://127.0.0.1:8546 in the browser where your wallet is, choose the network, Connect, then Deploy. On Ethereum mainnet it is two confirmations; where each transaction may create only one contract, the page goes one by one (five). It resumes where it stopped. The account that deploys owns the collection. `node scripts/find-deploy.cjs <owner>` finds the new KLab; put it in `src/lib/lab/chain.ts` (`DEPLOYED`). The owner's own tools (mint open/close, renderer switch) are kept outside this public repository.

Verify on Etherscan with `deploy/verify/standard-input.json` (see `deploy/verify/README.txt`).
